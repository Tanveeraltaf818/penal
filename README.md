# Server

1. npm i
2. TOKEN=secret123 PANEL_TOKEN=panel123 node server.js
3. Caddy/Nginx se TLS lagao (panel.aapka-domain.tld -> localhost:8080)
4. Panel: https://panel.aapka-domain.tld/p/?token=panel123

TOKEN apk ke Cfg.kt me jata hai, PANEL_TOKEN panel URL me.
Dono badal lo, default kabhi na rakho.
